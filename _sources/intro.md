# Welcome to BE 559

*Foundations of Biomedical Data Science and Machine Learning* (Boston University, Spring 2026).

This site collects the course's lecture notes and homework problem statements, organized by module.

## How this book is organized

The sidebar follows the five course modules:

1. Hypothesis testing
2. Regression and model fitting
3. Classification and clustering
4. Dimensionality reduction
5. Neural networks

Each module has an overview page listing its topics. Where lecture notes are posted (currently Modules 1 and 3), they nest underneath it. Homework is assigned once per module, so each homework sits on its own page right after its module (e.g. "Homework 3"), split into numbered parts.

Homework pages are Jupyter notebooks that show **problem statements only, with no solutions**. Look for the 🚀 rocket icon in the top-right corner of a homework page, then choose **Colab**, to open it directly in [Google Colab](https://colab.research.google.com). Submit your completed notebook as described in the syllabus.

Watch for 🚩 **Common mistake** notes: they flag errors that run without complaint but give the wrong answer.

The syllabus is in the appendix.
